# Basic Calculator

A responsive web-based **Basic Calculator** built using **HTML, CSS, and JavaScript**.
This project was developed as part of a college assignment to demonstrate front-end development skills and JavaScript-based arithmetic operations.

---

## Project Overview

The calculator allows users to perform standard mathematical calculations through an interactive interface.
It supports both **button input and keyboard input**, making it convenient and user-friendly.

---

## Features

* Perform basic arithmetic operations

  * Addition (+)
  * Subtraction (-)
  * Multiplication (*)
  * Division (/)

* Interactive and responsive user interface

* Keyboard input support

* Clear button to reset calculations

* Decimal number support

* Error handling for invalid expressions

* Smooth button animations and modern UI design

---

## Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout design
* **JavaScript (ES6)** – Calculator logic and functionality

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open **index.html** in any web browser.
4. Use the calculator buttons or keyboard to perform calculations.
